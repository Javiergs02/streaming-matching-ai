# Data Dashboard & BI Analytics

Interactive Business Intelligence application built with **Streamlit** for querying, analyzing, and reporting multi-platform streaming performance data.

## Features
- **Relational Catalog Integration:** Master series, seasons, episodes, and territorial mappings via PostgreSQL.
- **Transactional Event Store:** High-throughput streaming performance events in MongoDB.
- **Consolidated Business Reports:** Financial reconciliation, multi-currency conversion (USD / EUR / CNY), and corporate Excel reporting with stylized layouts.

## Running Locally
```bash
streamlit run app.py
```
